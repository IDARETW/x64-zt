# Replay 1.20 layout corrections for tools/gen_iw8_structs.py.
#
# The ACTS schema takes most layouts from the game-test build. Replay changed some of them. Each
# correction below matches the Replay loader code (the member that each Load_* routine reads, the
# size that it loads) or the runtime code that fills the member. A correction replaces the whole
# schema entry.
#
# Format:
#   struct <name> <size>          a record; members follow, one per line: <offset> <name> : <type>
#   union <name> <size>           as struct, all members at offset 0
#   alias <base name> <name>      use <name> wherever the schema uses <base name>
# Comments start with '#'.

# GPU buffer records. The loaders copy them as bytes (no pointer fixups); the renderer fills them.
# Load_GfxWrappedBaseBuffer loads 0x30, Load_GfxWrappedBuffer 0x40, Load_GfxWrappedRWBuffer 0x60,
# Load_GfxIndexBuffer 0x20.
